# personal-research

Every morning, spend 30 minutes researching experimental jazz production techniques and leave a concise report.

Generated by Agentic Project Architect. Architecture: **research**
(4 agent(s), estimated cost: LOW).

## Layout

- `AGENTS.md` — entry point for any agent runtime (Claude Code, OpenCode, ...)
- `.agent/` — architecture, policies, prompts (the "how")
- `project/` — goal, state, backlog, decisions, outputs (the "what")

## Project structure

This project's `project/` folder isn't the same for every project — each
optional subfolder is included only when it's actually useful here:

- ✓ `project/outputs/` — always included — the actual durable output of the project
- ○ `project/specs/` — skipped — a tiny project's goal.md is enough, no separate feature specs needed
- ○ `project/references/` — skipped — unlikely to need a dedicated place for source material at this size
- ✓ `project/research/` — included — a researcher role is part of this architecture
- ○ `project/plans/` — skipped — no planner role and no plan-execute-review pattern
- ✓ `project/experiments/` — included — research and software projects both tend to test hypotheses before committing
- ✓ `project/reviews/` — included — a review-capable role exists in this architecture
- ✓ `project/checkpoints/` — included — this architecture uses checkpoints (long-running/scheduled work)
- ✓ `project/telemetry/` — included — a long-lived or persistently-running project benefits from iteration history

Re-run `create-agent-project architecture . --recommend` after the project
changes shape (new domain, new roles, new work pattern) to see whether
this list should change too.
