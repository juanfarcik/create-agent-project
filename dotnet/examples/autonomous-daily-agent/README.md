# autonomous-daily-agent

Continuously monitor a project's backlog, pick the highest-value next action, and execute it every day without supervision unless something risky comes up.

Generated by Agentic Project Architect. Architecture: **autonomous-loop**
(3 agent(s), estimated cost: LOW-MEDIUM).

## Layout

- `AGENTS.md` — entry point for any agent runtime (Claude Code, OpenCode, ...)
- `.agent/` — architecture, policies, prompts (the "how")
- `.project/` — goal, state, backlog, decisions, outputs (the "what")

## Working on this project

Open this directory with your agent CLI and let it read `AGENTS.md` first.
